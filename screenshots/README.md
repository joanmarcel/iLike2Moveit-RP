# Screenshots

Drop the gallery images here, then uncomment the `## Gallery` block near the top of the main
[README](../README.md). Nothing else needs to change — the file names below are the ones that block
already references.

## Shot list

| File | What it should show |
|---|---|
| `villager.png` | Two or three villagers with different professions side by side, ideally in a village |
| `iron-golem.png` | Golem mid-stride, side view, so the walk cycle and pelvis sway read |
| `wolf.png` | A sitting wolf, front three-quarter view, with a pup nearby if possible |
| `cat.png` | Two or three cats of different breeds |
| `chicken.png` | Hen and chicks together; the rooster is a bonus |
| `fox.png` | A fox in a plains or taiga biome, side view — sleeping or stalking reads better than standing |

Optional: `banner.png`, a wide hero shot for the top of the README.

## Capture settings

These matter more than the composition — a good angle with the HUD in frame still looks like a bug report.

- **F1** to hide the HUD. No hotbar, no crosshair, no hand in the corner.
- **F5** for third person if you want the player out of frame entirely.
- `/time set day` and `/weather clear`. Dark or rainy shots hide the very detail the pack adds.
- Fullscreen (**F11**) at 1080p or better, so the mob is not a handful of pixels.
- Frame the mob at roughly a third of the image. Close enough to read the model, far enough for context.
- Turn off any shader pack — the point is what this pack does, not what the shader does.

## What not to use

Debug captures from a porting session: mob small and off-centre, HUD visible, the player's arm in the
corner. They are fine for verifying a rig and bad for a store page.
